## Etch-a-Sketch
A simple drawing grid built with HTML, CSS, and JavaScript. Hover over a square to color it in, just like a pen leaving a trail.

## How to use
1. Open `index.html` in your browser.
2. Move your mouse over the grid to draw.
3. Click **Custom Grid Size** to enter a new number of squares per side (max 100) and get a fresh grid.

## Features
- Grid created dynamically with JavaScript (no hardcoded HTML divs)
- Hover effect leaves a colored trail
- Random color per square
- Square darkens with each hover, fully colored after 10 hovers
- Button to reset the grid at a custom size

## Built with
- HTML
- CSS (Flexbox)
- JavaScript
